## <span style="color:#00DD55;">1. PROJECT OVERVIEW</span>

Fwogx402 is built around the idea that a meme can become a computational entity.  
Not an assistant, not a trading bot, but a system capable of:

- observing chain signals  
- interpreting meme‑driven sentiment  
- generating structured intents  
- regulating risk autonomously  
- evolving its narrative layer  

The mascot **Fwogx402.png** represents the visual identity of this system.

## <span style="color:#00BB44;">4. CORE CONCEPTS</span>

### Amphibious Intelligence
Green‑coded hybrid cognition model enabling simultaneous on‑chain and off‑chain reasoning.

### Intent Machine
All decisions collapse into a typed object:

```
Intent {
    StateView state
    RiskBudget budget
    Tag[] narrative_tags
    Constraint[] rules
}
```

### Meme‑Driven Signal Encoding
Sentiment becomes a quantitative input through **meme spectral transforms**.
